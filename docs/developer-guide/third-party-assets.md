# サードパーティアセットの管理ガイド

このドキュメントは、`com.murnana.unityroom` パッケージおよびサンプルに含まれる外部アセットを管理するためのルールをまとめたものです。

---

## 基本ルール

外部（サードパーティ）のアセットをプロジェクトに追加した場合は、**必ずプロジェクトルートの `THIRD PARTY NOTICES.md` を更新してください**。

このファイルは、テンプレートを利用する開発者が帰属表示を正しく行えるよう、すべての外部アセットの情報を一元管理します。

---

## 記載フォーマット

`THIRD PARTY NOTICES.md` に以下の形式でエントリを追加します。

```markdown
## [アセット名・提供元の通称]

| 項目 | 内容 |
|------|------|
| ファイル | `Assets/...（プロジェクト内のファイルパス）` |
| 著作者 | 著作者名 |
| 提供元 | <提供元サイトURL> |
| ライセンス | ライセンス名（<利用規約ページURL>） |
```

---

## チェックリスト

外部アセットを追加・変更・削除するときは、以下を確認してください。

- [ ] `THIRD PARTY NOTICES.md` に該当アセットのエントリが存在する
- [ ] ファイルパスが実際のパスと一致している
- [ ] 利用規約ページのURLが正確である
- [ ] アセットを削除した場合は、対応するエントリも削除した
