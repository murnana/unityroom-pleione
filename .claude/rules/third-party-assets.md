# Third-Party Asset Management

> **開発者向け日本語ドキュメント**: `docs/developer-guide/third-party-assets.md`
>
> このファイル（`.claude/rules/third-party-assets.md`）と上記ドキュメントは同じルールを記述しています。
> いずれかを変更した場合は、もう一方も必ず同じ内容に更新してください。

## Rule

外部（サードパーティ）のアセットをプロジェクトに追加した場合は、**必ず `THIRD PARTY NOTICES.md`（プロジェクトルート）を更新すること**。

## 記載フォーマット

`THIRD PARTY NOTICES.md` に以下の形式でエントリを追加する。

```markdown
## [アセット名・提供元の通称]

| 項目 | 内容 |
|------|------|
| ファイル | `Assets/...（プロジェクト内のファイルパス）` |
| 著作者 | 著作者名 |
| 提供元 | <提供元サイトURL> |
| ライセンス | ライセンス名（<利用規約ページURL>） |
```

## チェックリスト

外部アセットを追加・変更・削除するときは、以下を確認する。

- [ ] `THIRD PARTY NOTICES.md` に該当アセットのエントリが存在する
- [ ] ファイルパスが実際のパスと一致している
- [ ] 利用規約ページのURLが正確である
- [ ] アセットを削除した場合は、対応するエントリも削除した
